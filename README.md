## Features
- **Glassmorphism UI** — frosted panels, soft borders, layered glows
- **Animated backgrounds** — floating live-coding lines and particles
- **Scroll effects** — reveal-on-scroll, animated skill bars, counting stat numbers
- **Project filtering** — filter the grid by category, client-side
- **Fully responsive** — desktop, tablet, and mobile layouts with a hamburger menu
- **Working contact form** — validates input, then opens the visitor's mail client with the message pre-filled
- **Copy-to-clipboard** — one-click copy for email, WhatsApp, and phone
- **Accessibility & polish** — `prefers-reduced-motion` support and print styles
- **Extras** — loading screen, custom cursor glow, toast notifications, and a Konami-code easter egg
## Tech Stack
Plain **HTML5**, **CSS3** (custom properties, grid, flexbox, keyframe animations), and
vanilla **JavaScript** (ES6 IIFE modules). Fonts and icons are loaded from Google Fonts
and Font Awesome CDNs.

No frameworks, no bundler, no `npm install`.

## Getting Started
Just open the file in a browser:

```
portiforio.html
```

Or serve it locally with any static server:

```bash
python -m http.server 8000
# then visit http://localhost:8000/portiforio.html
```
